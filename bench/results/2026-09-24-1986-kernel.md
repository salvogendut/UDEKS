# Initial `1986` kernel-primitives results

Status: **preliminary, emulator-only, not an executive-CPU decision**.

Three runs per configuration produced identical results. Both shared-C
workloads matched independently computed checksums. Every MMU and CIA write was
read back unchanged, and all 128 VDC ready/select/read transactions completed.

| Case | Iterations | 8502 1 MHz | 8502 2 MHz | Z80 stock | Faster candidate |
|---|---:|---:|---:|---:|---|
| empty | 1 | 69 | 35 | 60 | — |
| direct switch dispatch | 128 | 36,979 | 18,489 | 13,634 | Z80, 1.36× |
| indirect table dispatch | 128 | 61,044 | 30,522 | 20,110 | Z80, 1.52× |
| event queue round trip | 32 | 33,517 | 16,759 | 22,524 | 8502, 1.34× |
| MMU same-state write/read | 128 | 2,510 | 1,255 | 4,168 | 8502, 3.32× |
| CIA same-state write/read | 128 | 2,510 | 1,255 | 4,174 | 8502, 3.33× |
| VDC ready/select/read | 128 | 4,294 | 2,147 | 10,302 | 8502, 4.80× |

Values are one-megahertz system ticks; lower is better. Ratios compare the
stock Z80 against the 2 MHz 8502.

## Interpretation

The dispatch cases reinforce the earlier shared-C results. SDCC's Z80 output
is faster both when C selects and directly calls one of four syscall handlers
and when it indexes an indirect function table. The indirect-table increment
over direct dispatch is 12,033 ticks on the 2 MHz 8502 and 6,476 ticks on the
Z80 for 128 calls.

The event queue reverses that outcome: cc65's 2 MHz 8502 implementation handles
32 validated four-byte event push/pop round trips 1.34 times faster. Queue
layout and index width will therefore matter when the permanent ABI is chosen.

The assembly device results strongly favor the 8502. The Z80's MMU and CIA
loops take more than 3.3 times as long, and its VDC loop takes 4.8 times as
long. This makes the 8502 device-access advantage quantitative rather than
merely an inference from available documentation.

These cases intentionally leave the current machine state unchanged. MMU and
CIA adapters repeatedly write their original value and verify it. The VDC
adapter polls readiness, selects update-address-high register 18, and reads its
data without modifying the register. A later display-pressure run must repeat
VDC work while real transfers and VIC activity are in progress.

The results do not yet answer whether a Z80 executive can profitably delegate
device work to the 8502. That requires measuring both ownership-transfer
directions and complete mailbox transactions. VICE and physical C128 results
also remain mandatory.
