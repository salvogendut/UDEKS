# Initial `1986` bidirectional handoff results

Status: **preliminary, emulator-only, not an executive-CPU decision**.

Three runs per configuration produced identical results. Every case completed
64 round trips, every peer count reached 64, and every mailbox request passed
magic, ABI, state, opcode, sequence, status, and transformed-result checks.
Each round trip contains two real MMU `$D505` ownership changes.

| Requester → responder | Work per round trip | 8502 1 MHz | 8502 2 MHz |
|---|---|---:|---:|
| 8502 → Z80 | bare handoff | 95.172 | 88.531 |
| 8502 → Z80 | full mailbox NOP | 434.266 | 373.125 |
| Z80 → 8502 | bare handoff | 65.453 | 45.969 |
| Z80 → 8502 | full mailbox NOP | 403.562 | 323.062 |

Values are one-megahertz system ticks per round trip; lower is better. The Z80
was stock in every run: two T-states per system tick, with
`double_z80_frequency = 0` and `tinker = 0`. The 8502-speed byte embedded in
each result independently confirmed the requested 1 or 2 MHz mode.

Subtracting the bare round trip from the full NOP gives the mailbox protocol
cost above arbitration and minimal dispatch:

| Requester | 8502 1 MHz | 8502 2 MHz |
|---|---:|---:|
| 8502 | 339.094 | 284.594 |
| Z80 | 338.109 | 277.094 |

## Interpretation

At the intended 2 MHz 8502 rate, a validated no-work offload costs about 373
system ticks when an 8502 executive asks the Z80 to work, and about 323 ticks
when a Z80 executive asks the 8502. A real offload must recover at least that
fixed cost through faster worker execution before it can improve throughput.
The subsequent [end-to-end size sweep](2026-09-24-1986-offload.md) locates
that crossover for copy, checksum, and transform jobs rather than assuming that
delegation is profitable.

The direction asymmetry is expected because a measured round trip includes the
requester's loop and validation plus the responder's dispatch. It is not a
claim that a bare `$D505` write has a direction-dependent electrical latency.
The bare case retains one shared peer-counter update so incomplete execution
cannot masquerade as a fast result.

The result does not select an executive. It does quantify the penalty behind
the earlier device-access result: a Z80 executive can delegate MMU, CIA, or VDC
work to the faster 8502 path, but each bounded request begins roughly 323 ticks
behind at 2 MHz under the current ABI. Conversely, an 8502 executive pays about
373 ticks before benefiting from a Z80 computational offload.
